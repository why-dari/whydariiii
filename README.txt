MARLEN — сайт мастерской

Откройте index.html в браузере. Все файлы и папку images нужно сохранять вместе.

Для проверки контрольной:
1. На странице «Заказ» две разные формы: заказ и контактные данные. Вторая открывается по нажатию на текст «Контактные данные». Каждая отправляется на https://httpbin.org/post в новую вкладку. Это публичный тестовый сервер: не вводите настоящие пароли и другие конфиденциальные данные. Если будете публиковать сайт, учитывайте, что значения полей по умолчанию видны всем посетителям исходного кода.
2. Страница «Паспорт» (dom.html) доступна из верхнего меню. Страница change.html доступна с неё по ссылке «Изменение данных по клику». В файл change.html можно зайти напрямую.
3. В dom.html и change.html год рождения указан как 2007. Проверьте день и месяц рождения и остальные паспортные поля.
4. Для задания DOM откройте dom.html, инструменты разработчика браузера (Console), исполните:
   document.getElementById("passport_surname").innerText
   document.getElementById("passport_name").innerText
   document.getElementById("passport_year").innerText
   Сделайте настоящий скриншот окна браузера с результатом и сохраните как images/dom_console.png.
   Затем в файле dom.html перед последним </main> вставьте строку:
   <p><img src="images/dom_console.png" alt="Получение данных из DOM" width="600"></p>
5. В задаче 1008 в «обе ёмкости» учитывается общий объем жидкости для одновременного заполнения обеих.
6. Для максимального соответствия заданию разместите проект на удаленном сервере (например, GitHub Pages) и проверьте публичную ссылку. Локальное открытие файла не выполняет этот пункт.
